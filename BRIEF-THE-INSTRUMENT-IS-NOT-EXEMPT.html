A shop-floor account

TheInstrument Is Not Exempt

Almost every fault this session was in the thing doing the looking

This is an account of one long session. It is not a manual and it will not be updated — it is correct about the days it describes and makes no claim about today.

It begins exactly where The Water Between stops: the voice pane outlined, unbuilt, blocked on nine files nobody had read. It ends with five instruments running unattended, a fifteenth pane reading a register, and the 936-line gap measured shut with 5,203 lines of margin.

In between, the voice platform was destroyed and recovered, and the probe built to watch it lied four times before it was allowed to speak.

A PROBE THAT REPORTS ON A FILE IT DID NOT VERIFY
IS THE SILENT SIGNATURE WEARING A PROBE'S COAT.

I · The probe, audited four times

The previous brief established that the specification was audited by the ship before the ship was audited by the specification. The same discipline was applied here, and it earned its keep immediately: four defects, all found by feeding the instrument real output rather than accepting a green run.

It read HTML as JavaScript

The first version ran its comment-and-string stripper over the whole document. An apostrophe in a paragraph opened a string that never closed; https:// in an href opened a line comment. The damage ran forward, blanking the script block beneath it.

The probe reported a live engine as unregistered. The engine was there. The instrument had erased it, and then reported confidently on what remained.

It could not see the only door

An independent grep found nine speak/play call sites per surface. The probe had attributed six and three. Among the misses:

onclick="Sovereign.Atlantica.speak('${key}', this)"

A handler inside an HTML attribute inside a template literal, blanked with every other string. It is the only entry point to Atlantica read-aloud on Page2. A pane built on that reading would have drawn the path as unreachable.

Call sites are now gathered from the code mirror, the literal mirror, and the static HTML region; receivers resolve through this and through local aliases; the remainder is published as unattributedCalls. The count reconciles — 19 of 19 on Page1, 9 of 11 on Page2, with both remainders named as the <audio> elements they are.

It went green on a file it could not parse

Fed a file whose unterminated string had swallowed a live engine, the probe reported zero findings and exited clean. The stripper now records where it ran off the end, and an unstrippable finding is blocking.

It measured each surface against a universe it does not live in

The first repository run reported six globals adrift on Page2 — Amenti.voice, throttle, conversation, listen, chat, doctrine — on the grounds that Page2 registers them and never calls them.

Page2 does not load the bundle at all. Its only local script is config.js. Every global from every readable file had been handed to every surface.

"Loaded is not used" about a file that was never loaded is a worse lie than the one the probe was built to catch, because it is confident and specific.

The same error ran the other way. Amenti.doctrine read as adrift on Page1 because the page never names it — the platform reads it, inside the bundle, in REG(). A reference in a file the surface loads is a reference.

A surface's universe is now its own inline code plus the files it actually loads. Nothing wider, nothing narrower. Verified by planting a real orphan — an engine with speak() and stop() that nothing calls — and confirming adrift still fires. That test caught a fifth defect: the candidate filter was dropping globals whose name lacked a speech word, so an engine called Amenti.speaker would have been invisible.

EIGHT OF ELEVEN FINDINGS IN THE FIRST REPOSITORY RUN WERE FALSE.
THE RUN WAS GREEN. THE COUNT WAS CONFIDENT. THE LINE NUMBERS WERE EXACT.

II · The engine was replaced, and nothing complained

At approximately 02:05, amenti-voice.js was replaced with the contents of VOICE.json. 644 lines of engine became 1,624 lines of JSON. Commit 0a4b396. The message read:

Update print statement from 'Hello' to 'Goodbye'

— describing work with no relation to either file. The commit was Verified. Signed. Three of five checks failing.

The signature attested that the captain made the change. It did not attest that the change was what the message said. Nothing else noticed. It was found by opening the file.

The file already carried one of the better headers in the fleet — a rule, the ownership line, THE VOICE PLATFORM, and forty lines on what changing it costs. Every line of it was overwritten too.

A WARNING ONLY WORKS ON SOMEBODY WHO IS READING.

RECOVER FROM THE BLOB, OR YOU RECOVER NOTHING.

III · What the engine turned out to say

Reading amenti-voice.js corrected a finding that had already been issued against Page2.

var PROFILES = { recital: 320, gabriel: 700, counsel: 320 };

Page2's 700 is not drift. It is a declared, priced decision: a surface's chunk boundaries are part of its cache key, so changing them orphans that surface's audio. Each surface keeps its own profile until somebody decides to pay for a re-render.

The probe had been about to report a documented ruling as a fault — and a register that cries fault on a decision already made teaches its reader to skip the findings, after which the one real fault goes past unread. Chunk sizes are now measured against the declared table, harvested from source. A matching size reports accepted, named. Only an undeclared size is drift. Verified by setting TARGET_CHARS to 640 in a fixture, where it goes straight to fault and names the three values it is not.

The same reading separated two jobs the fleet had been treating as one:

CONSOLIDATING THE CODE IS FREE.
CONSOLIDATING THE CACHE KEY IS NOT.
A SURFACE MAY DEFER THE SECOND AND STILL OWE THE FIRST.

Page2 has deferred the priced half deliberately. It has not done the free half, and that is now reported as its own finding rather than folded into the other.

IV · The gap, measured shut

The fault the pane exists for, from the previous brief: an IIFE at line 5989 asking for window.Amenti.chat, registered 936 lines too late, guard false, every call site silently taking the inline fallback.

The register now reads:

[confirmed] load-order-clear · Page1.html · Amenti.chat
    read at PARSE TIME on line 6096; available from line 893
    (amenti-core.bundle.js, blocking). 5203 lines of margin.

What binds is not the registration line — that comparison is meaningless across two files. It is the point on that surface at which the global becomes available: the line of a blocking <script src>, the line itself when inline, and never, at parse time, for a defer or async tag.

That branch was tested rather than assumed. One word changed in a fixture — blocking to defer — and the same line swings to:

[fault] load-order · Amenti.chat
    read at PARSE TIME on line 6096; registered by amenti-core.bundle.js,
    which is loaded defer and has therefore not run. The guard evaluates
    false and the call site takes whatever fallback exists, without a word.
BEING LOADED IS NOT BEING USED.

V · Unreachable is not absent

The mirror matches the ship is one of the eight lies, and it was said on a run where every fetch had failed. Nothing was compared; the absence of a difference was reported as a match.

probes/probe-gate.mjs compares every register the Glass Gate carries — ship against mirror, by sha256, never by size or date. If the clone fails, the job fails there and reports nothing about any register. It does not continue into a comparison against an empty directory and find no differences.

Its first run earned itself: fleet-manifest.js at 46,813 bytes on both sides with different content hashes — precisely the case a size check calls a match.

Open · the drift that healed before it was named
Before the probe could be extended to name the differing line, a push brought both sides into step. The drift was transient; what caused it is not known, and it will recur. The probe now names the first differing line and both sides of it, so the next occurrence answers the question.
UNREACHABLE IS NOT ABSENT,
AND ABSENT IS NOT EQUAL.

VI · The author shipped the fault he had just read

voice.yml, as first written, did a bare git push — fault #1 in scan.yml's own header, verbatim, onto a branch where two other workflows write. It also ran git diff --quiet on an untracked file, which reports no difference, announces "nothing to commit", and exits green with no register in the repository: the fault scan.yml records catching in itself on 16 August.

Both were written minutes after reading the paragraphs describing them.

A register of known faults is not a vaccine. It is a list, and a list must be checked against the thing being written, not merely read beforehand.

VII · The guard

A banner would not have saved the engine; the engine's banner was overwritten with it. So the guard checks shape, not content — only whether each file is still itself:

CheckWhy it matters
is javascripton 20 Aug the file began with {
PROFILESthe chunk profiles are the cache namespace
stopReadingthe brake; all three facades hang off it
composeStyleSTYLE is an input to the cache key
speak()the one entry point every facade calls
the facadesPage1 has call sites on both
400 linesa real edit does not halve a file; a replacement does

Not "did anything change". These files are edited legitimately and often, and a guard that fires on honest work is ignored — the same disease as a register that cries fault on a documented ruling. Page1 and Page2 are deliberately not watched, because they are under active edit.

Tested against the actual damage: fed last night's exact overwrite, it names six missing pieces, says why each matters, exits 1, and prints the recovery route including use the blob view. And it caught a case nobody had thought of — engine repaired, bundle never rebuilt. Page1 loads amenti-core.bundle.js, not the source, so a correct repair to one alone would leave the surface broken and look fixed.

On the missing brake, stated precisely

Sovereign.Voice.speak on the short path posts one reply, plays it once, and stops. No loop, no queue. The ceiling is one clip of one reply under 700 characters.

What is missing is the ability to interrupt that clip. The function is async, never re-checks AMENTI_VOICE_ON after its await, and carries no AbortController. Toggle voice off during the render — roughly twenty seconds for a 700-character reply, by the measured 7510 + 18.25 × chars — and the clip still arrives and still plays.

The repair is the code consolidation, not a patch: Amenti.voice.speak(text, {figure, register:'conversational', profile:'gabriel'}) inherits the brake, the abort and the fast opener, and keys identically — gabriel: 700 exists in PROFILES for exactly that call.

Recorded as a finding, not a fault, and deferred. Page2's speech has resisted two prior rebuilds. A surface that has defeated two attempts is telling you the estimate is wrong.

X · What is open

Open
The two replacements. Verify what produced 0a4b396 and the Harbor's replacement on 17 August. Until that is known, the guard is a smoke alarm on two files and the same actor can reach any other.

The manifest drift. Transient, cause unknown, will recur. The probe will name the line next time.

Fifteen panes or sixteen. The handover says sixteen; the registry holds fifteen. One is wrong, and it is the kind of small number that propagates.

The no-brake ruling. Belongs in spec/voice-accepted.json with its reason and date, so it is read as a decision rather than rediscovered as a problem.

XI · What this cost, and what it is worth

The previous brief closed on a finding: every fault it found lived in the water between two registers. This session found something adjacent and less comfortable.

The ship was almost entirely sound. Page2's 700 was a documented ruling. Page1's engine had already been consolidated correctly. The load order was right, with 5,203 lines of margin. Of the faults recorded here, five were in the instrument built to find faults, one was in the workflows written to run it, and one was an external replacement that no instrument was watching for.

The transferable version, for whoever inherits this:

An instrument is a claim about the world, and it is the one claim nobody checks — because checking it is indistinguishable, from the outside, from the work it was built to do. A probe with a defect does not go quiet. It goes green, and confident, and specific, and it hands you line numbers.

Every defect in this session's probe was found the same way: by taking its output and testing it against something that did not come from the probe. A grep. A fixture. A planted orphan. A second reading of the file it claimed to have read.

THE SHIP IS AUDITED BY ITS INSTRUMENTS.
THE INSTRUMENTS ARE AUDITED BY NOTHING —
UNLESS SOMEBODY POINTS SOMETHING ELSE AT THEM.
