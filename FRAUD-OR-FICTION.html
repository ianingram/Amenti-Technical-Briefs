Fraud or Fiction

The first honest cohort added to the roster from an external source — and the seventeen fictional presidents the source tried to smuggle in.

The source is a draft too.
— the lesson, learned in the first thirty seconds

The occasion

Expanding the roster without becoming the source.

The roster is a closed list — the hall knows only the souls in names.csv, and its wall is hard. To grow it (THE STANDING SLIP #52) the honest way is to draw from an external, checkable source, never from the model's memory (#54): the interface is the tool, not the source. This brief records the first cohort done that way — the US presidents — as the worked proof of the pattern.

It was chosen because it is small, modern, and unambiguous: a set where a wrong entry is obvious. Which turned out to matter, because the source handed us wrong entries immediately.

The first fetch

Sixty-three “presidents,” and a mechanical bastard.

The naive query — everyone Wikidata records as holding the office of President of the United States — returned 63 names. The property is polluted with fictional office-holders from film, television and comics, undated and indistinguishable, at the top of the list. A fetch-and-commit would have put every one of these on the roster:

Mr. Garrison Gonzo (Mechanical) Thor Doom 2099 Zartan Prez General Joseph Colton Glen Allen Walken President Winthrop Robert L. Booth Olivia Marsdin Quentin Trembley Thomas Kirkman Ed Kealty Phil Baker Roger Durling The President

This is the whole argument for the architecture, delivered in one screen. The source is not the truth; it is a draft that must itself be verified. An external reference is safer than the model's memory — but only because it can be checked, not because it is clean. Trusting it blind is the same failure as trusting the model blind, wearing a more respectable coat.

The pattern

Six steps, none skippable.

1
Fetch from a real source. A SPARQL query to Wikidata, not a recitation from memory. The model navigates to the source; it does not become it.
2
Filter the fiction. Constrain to actual humans ?p wdt:P31 wd:Q5 with a real birth date. The 17 fictional holders fall away; 45 real ones remain.
3
Complete the record. Pull both dates. Deaths were missing on the first pass; a second query recovered them — and caught a fresh fact memory might have missed: Carter, died 2024.
4
Cross-check the roster. Seven presidents were already aboard. Zero date conflicts with the existing roster — source and ship agree on every overlap, which is its own signal both are sound.
5
Let the guard fire. probe-roster over the expanded list: 1,049 souls, all placeable, zero bad dates, the long-life count unchanged. The sign-error guard (#46) passed the whole batch.
6
Record provenance. Every new row carries its Wikidata entity in the Links column. The row does not say Lincoln, 1809–1865; it says that per a citable source. The model pointed; the source confirmed; the row records both.

The presidents now take their place in time: Lincoln already aboard, now with the Roosevelts, the Adamses, Kennedy and Washington's whole line beside him on the timeline — each a dated bar, a name in alive beside them, an anchor the mention graph can reach. None with a room; none needed one. A soul needs no shelf to have a place in time.

The principle it proves

Fraud, fiction, and the wall between them.

Two ways a false entry reaches a roster. Fraud is the model inventing a date from memory and presenting it as fact — the séance. Fiction is an external source carrying something that was never real — Doom 2099, sitting in a reputable database beside George Washington. The ship guards against both by the same discipline, applied at the same stage: verification at the workbench, before anything lands.

The model's general knowledge is not banned — it is quarantined to the authoring stage, where every draft is checked. It navigated to the source, read the fiction for what it was, and filtered it. That is the honest use of a fallible intelligence: not as the record, but as the draftsman who finds the record and is never trusted to be it.

Fraud is what the mouth invents. Fiction is what the source repeats. The wall stops both, and it stands at the workbench, not the front desk.
